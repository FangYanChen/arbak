# ARBAK — Clan Heritage

## 🎮 Project Overview
*Arbak* is an interactive story about choices, consequences, and memory.  
This project is based on elements of Kyrygzstan's cultural heritage centered on family conflict and its long-lasting effects generationally.

---

## 🧠 Game Concept
Two brothers each make choices that lead to tragedy.  
The apping will allow the younger brother the opportunity to confront the loss, guilt, and accountibility for his clan's future.

The concept draws inspiration from:
- Kygryz folklore
- *Arbak* (ancestral spirits)
- Elements of the epic *Manas*

---

## ⚙️ Features
- Narrative interaction
- Emotionally driven story
- Atmospheric images
- Culture-based
- Dialogue (linear / choice-based)
